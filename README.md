## Portfolio focus

This repository is designed to show a thoughtful, real-world security architecture decision:

1. Problem statement: what the client environment looked like and why it was risky.
2. Architecture decision: the recommendation, the reasoning, and the controls.
3. Tradeoffs: what was considered and rejected, and why.
4. Outcome: what changed and what the business gained.

## Anonymization rules

- No client names.
- No real account numbers or ARNs.
- No real IP ranges.
- Use placeholders like `client-a`, `111122223333`, or `10.x.x.x`.
